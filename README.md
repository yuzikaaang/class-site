# 25级05班班级服务站（静态站点）

25级05班 一站式班级服务网站，聚合常用链接、公告、倒计时、公众号二维码等，可在微信内直接打开并添加到主屏幕。

## 维护须知（站规，每次改动前必读）

- **用户要求是最高优先级**：站主提出的每一条要求都必须执行，改动前不得违反或跳过任何已记录的用户要求。
- **要求全量留档**：用户提出的**所有要求**都会写入 `TUTORIAL.md` 的「用户要求台账」（第 10 节），本文件只做提示、不重复记录。
- **冲突要问**：若当前需求与过往要求矛盾，先向站主确认并同步更新规则，不得擅自取舍。
- **改动即入库**：每次用户提出要求或需求变更后，立即 `commit + push` 到 Gitee，不留本地未提交改动。
- 配合「三处同步」铁律：功能改动同步 站内公告 / 本文件「最近更新」/ TUTORIAL「更新记录」；**游戏内容、隐藏空间默认不进公告（除非站主明确要求）**，详见 TUTORIAL。
- **执行前先读站规**：每次执行任务前，完整阅读本「维护须知」与 `TUTORIAL.md`「用户要求台账」（第 10 节），逐项核对，确保不漏执行（三处同步 / 隐藏不进公告 / 整站 zip 打包等）。
- **整站打包**：每次改动后，将整个站点（排除 `.git`）重新打包为 `class-site-backup.zip` 并提交推送，确保下载到的是最新完整版。**修改前先备份**：每次开始新修改前，先把当前（修改前）状态打包为 `backup/class-site-backup-before-<时间戳>.zip`（进 git），要回档时据此包恢复。
- **公告规范**：站内公告须简洁、凝练、官方口吻；除「站主杂谈」与「用户要求」类外禁用「你/我/我们」等主观语气词；只发用户可见的站点功能，**仓库/维护内容（站规、zip 打包、README/TUTORIAL 更新说明等）不进公告**；分点公告每条换行（`\n`）。
- **敏感信息安全（红线）**：线上只上传密文——仓库严禁出现明文口令/密钥/Token/加密提示；仅 `secrets.json.enc` 可提交。解密口令永不入库（不入 README/TUTORIAL/注释/commit/hint），维护者本地记忆，解密仅本地完成。加密脚本与提示文件不入库。提交前 `git grep` 自检口令/token/key/hint/password 等必须为空。发生过明文入库事故须：轮换暴露密钥 + 改写 Git 历史抹除明文并强推 + 更新记录留档。
- **印象要求识别**：对话中含「如果/以后/比如」等条件或举例词的要求，即便未明说也视为正式要求，记入台账并推送。
- **公告分点**：单次更新含多条内容时，站内公告用编号分点（1. 2. 3. …）列出，每条换行。
- **操作清单**：执行前必须读完 `TUTORIAL.md`「0.1 执行前必读 · 操作清单」并逐项勾选（任何模型通用，防漏同步 zip / 漏三处同步）。
- **对话总结凝练**：每次用户对话后先凝练总结要求；有歧义主动询问；回复精炼省 token。

## 使用方式

- **查看/编辑内容**：直接编辑根目录 `index.html`（网站本身就是这一个文件）。
- **资源规范**：
  - 图标类：使用图床直链。
  - 二维码类：直接放入仓库根目录（避免图床审核不过）。
- **路径规范**：所有本地资源统一使用相对路径（`./xxx`），以同时兼容 WorkBuddy 根路径部署和 GitHub Pages 子路径部署。
- **主链接更新**：修改 `index.html` 后推送到 Gitee，Gitee→GitHub 镜像自动同步，GitHub Pages 通常几分钟内刷新（强制刷新用 `Ctrl/Cmd + F5`）。
- **安装到手机**：用手机浏览器打开链接 → 菜单「添加到主屏幕」，即可像 APP 一样使用，内容随网站实时更新。

## 备份与导出

- 网站内置「导出备份」功能（侧边栏底部按钮）：输入备份密码后下载完整版 `class-site-backup.zip`（含全部网站内容）。
- 备份密码在站内以 SHA-256 哈希存储，不在源码中出现明文。
- 导出 zip 由维护者每次内容更新后同步更新。

## 令牌管理

- 令牌已加密存储在 `secrets.json.enc`（AES-256-CBC + PBKDF2 迭代 20 万次），**密码由维护者保管**。
- **密码提示：6 位数字**（详见 `secrets-hint.txt`，不包含真实密码）。
- 新对话需要编辑仓库时，向 AI 提供密码即可解密获取账号与令牌。
- 解密：`./scripts/decrypt-secret.sh <密码>`；加密：`./scripts/encrypt-secret.sh <密码>`。
- 不要在文档或对话中明文暴露令牌。
