# 25级05班班级服务站

一个为 25级05班 打造的**一站式班级服务网站**：公告、作业、资料、课表、点歌、倒计时、小游戏……打开即用，也能「安装」到手机桌面像 App 一样使用，支持离线访问。

- 打开链接就能用，**无需注册登录**；注册账号仅为云同步个人数据（可选）
- 手机 / 平板 / 电脑自适应，暗色模式自动跟随
- 可添加到主屏幕（PWA），断网也能打开

## 功能一览

### 📢 首页
- **班级公告**：按「网站内部 / 🔔 重要更新 / 班级事务 / 站主杂谈」分类，支持搜索、按时间范围筛选；重要消息会置顶，班级活动还会进站弹窗提醒 + 右下角悬浮球随时回看
- **每日日报**：当日热点聚合
- **今日班级签**：每天抽一张，次日 0 点刷新
- **倒计时**：学期进度、法定节假日，精确到秒。节日日期**由站内自动推算**（农历节日用内置万年历数据换算，清明按节气表），随年份滚动生成、**不用手动维护**；已经过去的节日当天起就不再显示

### 🧰 各板块
| 板块 | 内容 |
|------|------|
| **常用服务** | 点歌平台（VoiceHub）、作业查看（Classworks） |
| **大屏服务** | 班级课表（ClassIsland）、听歌平台（EchoMusic） |
| **学习资料** | 课堂笔记、教学课件（答对班级小问题解锁云盘链接；因网络问题暂停开放中） |
| **成绩查询** | 考试成绩查询入口（易查分） |
| **班级事务** | 意见反馈（匿名提建议 / 反映问题）、班级活动 |
| **其他工具** | 个人资料查询、番茄时钟、私人云盘（管理密码）、每日日报等实用小工具 |
| **📲 安装为应用** | Windows / iPhone / 安卓各品牌一键安装到桌面教程 |

> **卡片堆叠（试验功能，默认关闭）**：同一板块下有两个以上入口时，卡片会层叠成一沓只露出最上面一张（右上角标着共几个入口）。点 **↑ ↓** 可以上下轮换着看，也可以用鼠标滚轮或在手机上直接上下滑动切换；想看全部就点 **展开全部**，按钮点完再点 **收起** 回到堆叠。只有一个入口的板块不堆叠。
>
> 这个效果**还在测试中、观感不太稳定**，所以默认是关的（板块里的卡片按传统方式平铺罗列）。想试试就去「自定义设置 → 动效」里手动打开，打开时会提示一次；觉得不好用随时关掉即可，不习惯的建议保持关闭。

### 🎮 隐藏娱乐天地
站内藏了十几款小游戏（贪吃蛇、俄罗斯方块、像素飞鸟、涂鸦跳跃、打砖块、五子棋、中国象棋、消消乐、记忆翻牌、扫雷、井字棋、打地鼠、飞机大战等）和外站小游戏入口，还有隐藏空间彩蛋——线索藏在日常交互里，自己去探索才有意思。

> 部分游戏达标可领**点歌券**：从全班名单中选自己的名字，每款游戏每人每周一张，下周一 0 点刷新。
>
> 四款主要游戏（贪吃蛇 / 像素飞鸟 / 俄罗斯方块 / 涂鸦跳跃）有站内排行榜，分**历史总榜**（历史最高分）和**周榜**（本周最高分）两个榜。**每款游戏的成绩、局数、时长各算各的，不跨游戏合并**——上午玩贪吃蛇、下午玩飞鸟是两码事。

### 🎨 自定义设置
侧边栏「⚙️ 自定义设置」，想把界面调成自己的样子就用它：

- **排序**：首页四大板块、侧栏导航、板块内卡片、小游戏列表、公告分类标签都能拖着排（长按把手拖动，或点 ▲▼ 微调）。**站主以后新加的卡片会自动排在你排好的后面，不会丢**
- **字号**：六档可调（85% ~ 135%），**只放大文字，卡片和间距不变**
- **背景**：跟随主题 / 纯色 / 预设渐变 / 上传本地图片，还能调蒙层深浅；选到深色背景会自动切成夜间模式，保证文字看得清
- **动效**：一键开关全部动效（跟随系统的「减少动态效果」设置也会自动生效）；另可单独开关**卡片堆叠**（试验功能，默认关闭）——打开后板块里的卡片层叠成一沓，关掉则恢复平铺罗列
- **导出 / 导入**：配置可导出成文件，换设备时用「数据管理」或直接在这里导入即可，本机已有的内容不会被冲掉

> 所有设置只保存在你自己的设备上，不影响别人看到的界面。

### 👤 账号与云同步
侧边栏「👤 登录 / 注册」，登录后可以：

- **云同步**：把主题、界面设置、作业打勾、签到记录等**个人数据**同步到云端，换手机登录同一账号点「从云端恢复」就都回来了。登录时**每分钟一次双向心跳**，站里能实时看到谁在线
- **改密码**：原密码验证后修改，改完其他设备会自动退出登录
- **不登录也完全不影响使用**——数据照样存在你自己手机上，只是换设备不会自动跟着走

> 🔒 密码用 bcrypt 加密后存储，**站主也看不到明文**。云端只存你自己的个人数据，公告/资料这类站内容不会同步。
>
> 🛡 登录 / 注册需要**拖动滑块**做一次人机验证（纯前端，不收集任何信息），用来挡掉脚本批量尝试。

### 🛠 管理员后台
站主（管理员）在个人中心可进入后台：

- **用户管理**：查看所有注册同学、重置密码、启用/禁用、调整角色、强制下线、删除账号；「最后上线」显示的是**实时在线状态**（靠会话心跳判定，不是在线的就显示最后活跃时间）
- **资料管理**：全班通讯录的统一录入与审核，支持 Excel 导入导出；**资料字段可以自己加**（见下）
- **通用弹窗**：开屏弹 / 板块弹统一在这里配置，可选「迎新橙卡」样式、设置板块顶部横幅，支持班级公告与作业通知自动取数
- **游戏数据**：四款主要游戏的最高分、各游戏局数 / 时长分列展示（**不跨游戏合并**），另有点歌券发放记录
- **抽歌排期**：设置每周放哪些歌、排除名单
- **版本更新**：维护前台展示的版本记录
- **数据统计**：注册人数、7 天内活跃、云端占用、同学们最常同步哪些数据
- **数据管理**：查看/修改/删除任意用户的云端数据
- **操作日志**：所有管理操作留有记录，可追溯

#### 🧩 资料字段可以自己加（v2.4.0）
「资料管理」页右上角有 **字段管理**，不用改一行代码就能给同学资料加新项目（学籍号、宿舍号、身份证号……）：

| 能力 | 说明 |
|------|------|
| **新增字段** | 填中文名 + 英文键名（如 `school_id`）+ 可见范围，回车即生效 |
| **改名称 / 排序** | 中文名随时改；排序值决定它排在资料表第几列 |
| **删除字段** | 只有自己加的字段能删（系统字段会带崩代码，已禁用）；删了会连同全班该字段的值一起消失，会二次确认 |
| **快捷切换可见范围** | 每个字段后面三个小按钮，一键在「公开 / 班委可见 / 仅本人」之间切 |
| **单人例外** | 在某个同学的「编辑」弹窗里单独设「这个字段对他怎么显示」，只对他一个人生效 |
| **Excel** | 导出的表头用中文名；导入时按表头自动认字段，认不出的列不会乱写 |

**可见范围是怎么算的？** 一句话：**你调过的字段你说了算，你没动过的字段尊重同学**。

| 情况 | 结果 |
|------|------|
| 你在「字段管理」里**改过**某个字段的全班可见范围 | **以你为准**，同学自己在个人中心设的「仅自己可见」不再生效（可以放宽也可以收窄） |
| 你在某个同学的**编辑弹窗**里单独设了例外 | **以你为准**，只对他一个人生效，同样可以放宽也可以收窄 |
| 你**从没动过**的字段 | **尊重同学** —— 他说不想公开，就一定不公开（只能收窄，不能变宽） |

> 同学在个人中心会看到一句说明：「你已把部分联系方式设为仅自己可见，同学查不到；站主为核对资料在后台仍能看到，若站主调整过该字段的可见范围，则以站主设置为准。」—— 知情权清清楚楚。
>
> 后台编辑弹窗里也会反向提醒你：某个同学自己设了私密时会标一行小字，如果你覆盖了他，会标「已被你覆盖」。

> 说明：**身份证号**这类敏感字段默认就是「仅本人可见」，同学本人在「我的资料」里能看到，别人查不到。自定义字段默认也是「仅本人」，需要对外展示时再去字段管理里调。

## 使用方式

### 添加到手机桌面（推荐）
1. 用**手机浏览器**打开主链接（iPhone 用 Safari，安卓用 Chrome / 自带浏览器）
2. 点浏览器菜单 → 「添加到主屏幕」
3. 桌面出现图标，之后一点即开，和 App 一样

Windows / Mac 电脑也可以在浏览器地址栏右侧点「安装」按钮。不会装的话，站内「📲 安装为应用」有分品牌图文教程。

### 微信里怎么用
主链接在微信内可直接打开。部分外站（点歌平台、Classworks 等）在微信内会引导你用浏览器打开，按提示走就行。

### 断网 / 连不上服务器时
站点本身是 PWA，**断网也能打开**（内容走本地缓存）。如果连不上服务端（云同步、公告更新等），页面顶部会明确提示：

> ⚠️ 连接不到服务端，当前显示的是本地缓存 · 请检查网络，或切换到流量（移动数据）再试

按提示切换网络后会自动重试；本地已有的数据不会丢。

### 数据管理
侧边栏「💾 数据管理」可以：
- **导出 / 复制**本站保存在本设备的全部数据（游戏记录、班级签等），换设备或清缓存前导出一份，之后一键导入即可恢复。导出时用自己设置的密码加密，**密码请务必记住**（没有找回机制）
- **重置游戏数据**：清空所有游戏记录
- **全部清理**：清空本机站点数据（保留班级签、点歌券记录）

## 常见问题

**Q：作业怎么查？怎么标记已完成？**
A：假期作业发布后，打开网站的进站弹窗点「查看作业」即可直达到位；也可从「常用服务 → 作业查看 → 📝 查看当前作业」进入，或用「📅 历史作业（日期）」按日历回看。每条作业**点一下即可勾选「已完成」**（再点取消），进度显示在科目右上角，记录保存在本机。简化版教程见仓库 [`作业查看教程.md`](作业查看教程.md)。

**Q：作业显示不全 / 同步不及时？**
A：因校园网限制，班级电脑端的 Classworks 连不上服务器，站内作业由站主手动同步，实际以老师线下布置为准。

**Q：点歌券怎么用？**
A：游戏达标后按提示选名字领券 → 复制券码 → 到点歌平台点歌时输入券码即可核销。每款游戏每人每周一张。

**Q：换了手机 / 清了缓存，游戏记录没了？**
A：**推荐注册登录后用「云同步」**——登录账号 → 点「立即同步」，换设备登录同一账号 → 点「从云端恢复」即可。不想注册的话，也可以走老办法：「数据管理」导出 → 新设备导入；界面设置（排序 / 字号 / 背景）用「自定义设置」里的「导出配置」同样能带走。

**Q：必须注册才能用吗？**
A：**不必**。不登录时站点功能和以前完全一样，数据都存在你自己手机上。注册只是为了换设备时方便，以及让站主在需要时能帮你处理数据问题。

**Q：云端会存我的什么？**
A：只存**你自己的个人数据**（主题、界面设置、作业打勾、签到、点歌备注等），公告和资料这类站内容不存。管理接口里也看不到你的密码——密码只有加密后的哈希。

**Q：链接打不开？**
A：站在微信里先试试「在浏览器打开」；仍然不行多半是网络问题，切成流量（移动数据）或换个网络再试。站点只有一个入口地址，不存在「换备用链接」这一说了。

**Q：网站会一直更新吗？**
A：会。内容随仓库实时更新，打开即是最新版；装到桌面后无需重新安装。

## 更新日志

> 完整历史可在后台「版本更新」面板查看，这里只列近几个大版本。

### v2.5.1（2026-10-11）—— 修复登录滑块验证码
- **修复（重要）**：登录 / 注册的滑块验证码**拖到底也提示「不匹配」**，怎么拖都过不去。
  根因是拼图块被画在了画布左上角（`x=0`），于是它只能在左边缘附近滑动，
  而缺口开在右半边 `targetX` 处 —— 两者**永远对不上**；偏偏判定逻辑又按「拖到底=通过」放行，
  形成了「判定说通过、眼睛看没对齐」的错位，用户自然以为自己没拖准。
  现在拼图块与缺口画在**同一坐标**，拖到底正好嵌进缺口，视觉与判定完全一致
- **一并修复**：画布宽度曾在弹窗刚插入、布局还没完成时取到 0，退回兜底宽度 300，
  与真实宽度（346）不符，又叠了一层横向错位。现在改为先重试几帧、拿到真实宽度再绘制
- 新增 3 条回归护栏断言（含「**禁止**把拼图块画在 x=0」），防止此问题复发
- 测试 1006 → **1009 项全绿**

### v2.5.0（2026-10-11）—— 真在线状态 + 登录验证码 + 全站去 emoji
- **真·在线检测（重要）**：以前「在线」只能看最后登录时间，容易误判。现在登录后**每分钟双向心跳**
  （前端发一次、服务端回一次 `pong`），按**会话粒度**记录 `sessions.last_seen_at` —— 不再是你登过一次
  就一直挂着「在线」。后台「用户管理」和「在线会话」都按这个口径显示
- **登录 / 注册加人机验证**：拖动滑块拼图，纯前端实现（不联网、不上传、不收集任何信息），
  用来挡掉脚本批量注册和撞库
- **游戏数据不再跨游戏合并**：以前后台会把一个人在所有游戏里的时长加成「总时长」并据此排序 ——
  但上午玩贪吃蛇、下午玩飞鸟是两码事，加在一起没有意义。现在**各游戏独立展示**（各自最高分 / 局数 / 时长），
  排序改成「最近玩过谁」，汇总口径改成「累计局数（局）」
- **全站图标统一为 SVG 图标库**：彻底移除运行时的 emoji → 图标替换引擎（它靠 `MutationObserver` 监听
  整页 DOM，和每秒刷新一次的倒计时打架，导致 emoji **每秒闪一下**）。现在全部改成静态 SVG 图标，
  **闪烁消失**。公告 / 作业正文里的手写 emoji 也在渲染时一次性转成图标
- **连不上服务端有明确提示**：网络中断或服务端不可达时，页面顶部会显示「连接不到服务端，当前显示本地缓存 ·
  请检查网络，或切换到流量（移动数据）再试」，恢复后自动消失
- **取消备用链接**：旧的 Gitee Pages 早已下线，WorkBuddy 托管那条微信内打不开、还容易误导同学，
  现在全站只有 GitHub Pages 一个入口；README 与站内文案同步精简
- 测试从 911 项扩到 **1006 项全绿**

### v2.4.1（2026-10-09）—— 后台权力最大 + 手机端排版修复
- **⚠️ 可见性语义调整（重要）**：取消 v2.4.0 的「三层取严」，改为**「你调过的字段你说了算，你没动过的尊重同学」**。

## 技术说明

- 前端：纯静态 PWA —— 单文件 `index.html` + `games/` 小游戏 + Service Worker 离线缓存
- 图标：站内不用 emoji 渲染，统一走内置的 **Lucide SVG 图标库**（避免 emoji 在刷新时闪烁、各系统外观不一）
- 后端：Serverless 云函数（当前部署在 Cloudflare Workers）+ 云数据库，支撑账号登录、个人数据云同步、云端内容（公告 / 作业 / 重要日期 / 每日一言）与管理员后台；后端说明见 [`api/README.md`](api/README.md)
- **不登录也完全可用**：不注册时个人数据只保存在你自己的设备（localStorage）里，不上传服务器
- 仓库开源：GitHub `yuzikaaang/class-site`（主仓库，GitHub Pages 直接发布）；Gitee `zikang0529/class-site` 为镜像
- 站内「导出备份」可下载完整站点备份包（需备份密码）
