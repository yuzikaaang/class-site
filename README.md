# 25级05班班级服务站

一个为 25级05班 打造的**一站式班级服务网站**：公告、作业、资料、课表、点歌、倒计时、小游戏……打开即用，也能「安装」到手机桌面像 App 一样使用，支持离线访问。

- 打开链接就能用，**无需注册登录**；注册账号仅为云同步个人数据（可选）
- 手机 / 平板 / 电脑自适应，暗色模式自动跟随
- 可添加到主屏幕（PWA），断网也能打开

## 功能一览

### 📢 首页
- **班级公告**：按「网站内部 / 🔔 重要更新 / 班级事务 / 站主杂谈」分类，支持搜索、按时间范围筛选；重要消息会置顶，班级活动还会进站弹窗提醒 + 右下角悬浮球随时回看
- **每日一言**：完全随机切换（不按顺序轮播），联网时会自动从网络名言库换一句
- ~~**学习卡片**~~：**暂时隐藏中**（v2.6.1 起）。功能代码和后台配置都还在，站主修好问题后会重新打开
- **每日日报**：当日热点聚合
- **今日班级签**：每天抽一张，次日 0 点刷新
- **倒计时**：学期进度、法定节假日，精确到秒。节日日期**由站内自动推算**（农历节日用内置万年历数据换算，清明按节气表），随年份滚动生成、**不用手动维护**；已经过去的节日当天起就不再显示

### 🧰 各板块

| **常用服务** | 点歌平台（VoiceHub）、作业查看（Classworks） |
| **大屏服务** | 班级课表（ClassIsland）、听歌平台（EchoMusic） |
| **学习资料** | 课堂笔记、教学课件（答对班级小问题解锁云盘链接；因网络问题暂停开放中） |
| **成绩查询** | 考试成绩查询入口（易查分） |

> **卡片堆叠（试验功能，默认关闭）**：同一板块下有两个以上入口时，卡片会层叠成一沓只露出最上面一张（右上角标着共几个入口）。点 **↑ ↓** 可以上下轮换着看，也可以用鼠标滚轮或在手机上直接上下滑动切换；想看全部就点 **展开全部**，按钮点完再点 **收起** 回到堆叠。只有一个入口的板块不堆叠。
>
> 这个效果**还在测试中、观感不太稳定**，所以默认是关的（板块里的卡片按传统方式平铺罗列）。想试试就去「自定义设置 → 动效」里手动打开，打开时会提示一次；觉得不好用随时关掉即可，不习惯的建议保持关闭。

### 🎮 隐藏娱乐天地
站内藏了十几款小游戏（贪吃蛇、俄罗斯方块、像素飞鸟、涂鸦跳跃、打砖块、五子棋、中国象棋、消消乐、记忆翻牌、扫雷、井字棋、打地鼠、飞机大战等）和外站小游戏入口，还有隐藏空间彩蛋——线索藏在日常交互里，自己去探索才有意思。

> 部分游戏达标可领**点歌券**：从全班名单中选自己的名字，每款游戏每人每周一张，下周一 0 点刷新。
>
> 四款主要游戏（贪吃蛇 / 像素飞鸟 / 俄罗斯方块 / 涂鸦跳跃）有站内排行榜，分**历史总榜**（历史最高分）和**周榜**（本周最高分）两个榜。**每款游戏的成绩、局数、时长各算各的，不跨游戏合并**——上午玩贪吃蛇、下午玩飞鸟是两码事。

### 🎨 自定义设置
侧边栏「⚙️ 自定义设置」，想把界面调成自己的样子就用它：

- **排序**：首页四大板块、侧栏导航、板块内卡片、小游戏列表、公告分类标签都能拖着排（长按把手拖动，或点 ▲▼ 微调）。**站主以后新加的卡片会自动排在你排好的后面，不会丢**
- **字号**：六档可调（85% ~ 135%），**只放大文字，卡片和间距不变**
- **背景**：跟随主题 / 纯色 / 预设渐变 / 上传本地图片，还能调蒙层深浅；选到深色背景会自动切成夜间模式，保证文字看得清
- **动效**：一键开关全部动效（跟随系统的「减少动态效果」设置也会自动生效）；另可单独开关**卡片堆叠**（试验功能，默认关闭）——打开后板块里的卡片层叠成一沓，关掉则恢复平铺罗列
- **导出 / 导入**：配置可导出成文件，换设备时用「数据管理」或直接在这里导入即可，本机已有的内容不会被冲掉

> 所有设置只保存在你自己的设备上，不影响别人看到的界面。

### 👤 账号与云同步
侧边栏「👤 登录 / 注册」，登录后可以：

- **云同步**：把主题、界面设置、作业打勾、签到记录等**个人数据**同步到云端，换手机登录同一账号点「从云端恢复」就都回来了。登录时**每分钟一次双向心跳**，站里能实时看到谁在线
- **改密码**：原密码验证后修改，改完其他设备会自动退出登录
- **不登录也完全不影响使用**——数据照样存在你自己手机上，只是换设备不会自动跟着走

> 🔒 密码用 bcrypt 加密后存储，**站主也看不到明文**。云端只存你自己的个人数据，公告/资料这类站内容不会同步。
>
> 🛡 登录 / 注册需要**填一次图形验证码**（照着屏幕上的图输入 4 位数字，会自动弹数字键盘；纯前端，不收集任何信息），用来挡掉脚本批量尝试。看不清可以点右上角换一张。

### 🛠 管理员后台
站主（管理员）在个人中心可进入后台：

- **用户管理**：查看所有注册同学、重置密码、启用/禁用、调整角色、强制下线、删除账号；「最后上线」显示的是**实时在线状态**（靠会话心跳判定，不是在线的就显示最后活跃时间）
- **资料管理**：全班通讯录的统一录入与审核，支持 Excel 导入导出；**资料字段可以自己加**（见下）
- **通用弹窗**：开屏弹 / 板块弹统一在这里配置，可选「迎新橙卡」样式、设置板块顶部横幅，支持班级公告与作业通知自动取数
- **游戏数据**：四款主要游戏的最高分、各游戏局数 / 时长分列展示（**不跨游戏合并**），另有点歌券发放记录
- **抽歌排期**：设置每周放哪些歌、排除名单
- **版本更新**：维护前台展示的版本记录
- **数据统计**：注册人数、7 天内活跃、云端占用、同学们最常同步哪些数据
- **数据管理**：查看/修改/删除任意用户的云端数据
- **操作日志**：所有管理操作留有记录，可追溯

#### 🧩 资料字段可以自己加（v2.4.0）
「资料管理」页右上角有 **字段管理**，不用改一行代码就能给同学资料加新项目（学籍号、宿舍号、身份证号……）：

| 能力 | 说明 |
|------|------|
| **新增字段** | 填中文名 + 英文键名（如 `school_id`）+ 可见范围，回车即生效 |
| **改名称 / 排序** | 中文名随时改；排序值决定它排在资料表第几列 |
| **删除字段** | 只有自己加的字段能删（系统字段会带崩代码，已禁用）；删了会连同全班该字段的值一起消失，会二次确认 |
| **快捷切换可见范围** | 每个字段后面三个小按钮，一键在「公开 / 班委可见 / 仅本人」之间切 |
| **单人例外** | 在某个同学的「编辑」弹窗里单独设「这个字段对他怎么显示」，只对他一个人生效 |
| **Excel** | 导出的表头用中文名；导入时按表头自动认字段，认不出的列不会乱写 |

**可见范围是怎么算的？** 一句话：**你调过的字段你说了算，你没动过的字段尊重同学**。

| 情况 | 结果 |
|------|------|
| 你在「字段管理」里**改过**某个字段的全班可见范围 | **以你为准**，同学自己在个人中心设的「仅自己可见」不再生效（可以放宽也可以收窄） |
| 你在某个同学的**编辑弹窗**里单独设了例外 | **以你为准**，只对他一个人生效，同样可以放宽也可以收窄 |
| 你**从没动过**的字段 | **尊重同学** —— 他说不想公开，就一定不公开（只能收窄，不能变宽） |

> 同学在个人中心会看到一句说明：「你已把部分联系方式设为仅自己可见，同学查不到；站主为核对资料在后台仍能看到，若站主调整过该字段的可见范围，则以站主设置为准。」—— 知情权清清楚楚。
>
> 后台编辑弹窗里也会反向提醒你：某个同学自己设了私密时会标一行小字，如果你覆盖了他，会标「已被你覆盖」。

> 说明：**身份证号**这类敏感字段默认就是「仅本人可见」，同学本人在「我的资料」里能看到，别人查不到。自定义字段默认也是「仅本人」，需要对外展示时再去字段管理里调。

## 使用方式

### 添加到手机桌面（推荐）
1. 用**手机浏览器**打开主链接（iPhone 用 Safari，安卓用 Chrome / 自带浏览器）
2. 点浏览器菜单 → 「添加到主屏幕」
3. 桌面出现图标，之后一点即开，和 App 一样

Windows / Mac 电脑也可以在浏览器地址栏右侧点「安装」按钮。不会装的话，站内「📲 安装为应用」有分品牌图文教程。

### 微信里怎么用
主链接在微信内可直接打开。部分外站（点歌平台、Classworks 等）在微信内会引导你用浏览器打开，按提示走就行。

### 断网 / 连不上服务器时
站点本身是 PWA，**断网也能打开**（内容走本地缓存）。如果连不上服务端（云同步、公告更新等），页面顶部会明确提示：

> ⚠️ 连接不到服务端，当前显示的是本地缓存 · 请检查网络，或切换到流量（移动数据）再试

按提示切换网络后会自动重试；本地已有的数据不会丢。

> **什么时候才会弹这条提示？** 只有**连续两次心跳都失败**才弹 —— 一次抖动不会打扰你。
> 相反，只要**有任何一条请求成功过**，计数就立刻清零（能通就说明网络没问题）。
> 所以「明明有网却弹提示」的情况已经基本不会出现了。
>
> **点「重试」会发生什么？** 不会像以前那样点了没反应：横幅会变成
> 「正在刷新… 剩余 60 秒」并**每秒走动**，期间每 10 秒真的再试一次；
> 连上就显示「连接已恢复」再自动收起，60 秒还没成功就回到原来的提示，可以再点。

### 更新到最新版本（v2.6.4 新增）

页面会**自己检查更新**，不用你操心：进站时查一次，从后台切回来时查一次，之后每 5 分钟再查一次。

如果发现线上有更新的版本，页面底部那行版本号会变成醒目的：

> **发现新版本 · 点击立即更新（当前 v2.x.x）**

点它一下就行 —— 会自动清掉旧缓存、重新加载到最新版。

设置面板（侧边栏「自定义设置 → 数据」）里也有「版本与更新」，能看到**当前版本**和**线上版本**两个号，还有「检查更新」「强制刷新」两个按钮。

> **手机上怎么都不更新？** 试这个顺序：
> 1. 点页面底部那行「发现新版本」直接更新
> 2. 还不行 → 「自定义设置 → 数据 → 强制刷新」
> 3. 仍然不行 → 把页面**完全关掉**（不是切到后台，是真的划掉）再重新打开
>
> 第 3 步之所以必要：iPhone 把它加到主屏后，浏览器长期不检查更新，而新版本装好了、开着的旧页面也不会自己重新加载。

### 数据管理
侧边栏「💾 数据管理」可以：
- **导出 / 复制**本站保存在本设备的全部数据（游戏记录、班级签等），换设备或清缓存前导出一份，之后一键导入即可恢复。导出时用自己设置的密码加密，**密码请务必记住**（没有找回机制）
- **重置游戏数据**：清空所有游戏记录
- **全部清理**：清空本机站点数据（保留班级签、点歌券记录）

## 常见问题

**Q：作业怎么查？怎么标记已完成？**
A：假期作业发布后，打开网站的进站弹窗点「查看作业」即可直达到位；也可从「常用服务 → 作业查看 → 📝 查看当前作业」进入，或用「📅 历史作业（日期）」按日历回看。每条作业**点一下即可勾选「已完成」**（再点取消），进度显示在科目右上角，记录保存在本机。简化版教程见仓库 [`作业查看教程.md`](作业查看教程.md)。

**Q：作业显示不全 / 同步不及时？**
A：因校园网限制，班级电脑端的 Classworks 连不上服务器，站内作业由站主手动同步，实际以老师线下布置为准。

**Q：点歌券怎么用？**
A：游戏达标后按提示选名字领券 → 复制券码 → 到点歌平台点歌时输入券码即可核销。每款游戏每人每周一张。

**Q：换了手机 / 清了缓存，游戏记录没了？**
A：**推荐注册登录后用「云同步」**——登录账号 → 点「立即同步」，换设备登录同一账号 → 点「从云端恢复」即可。不想注册的话，也可以走老办法：「数据管理」导出 → 新设备导入；界面设置（排序 / 字号 / 背景）用「自定义设置」里的「导出配置」同样能带走。

**Q：必须注册才能用吗？**
A：**不必**。不登录时站点功能和以前完全一样，数据都存在你自己手机上。注册只是为了换设备时方便，以及让站主在需要时能帮你处理数据问题。

**Q：云端会存我的什么？**
A：只存**你自己的个人数据**（主题、界面设置、作业打勾、签到、点歌备注等），公告和资料这类站内容不存。管理接口里也看不到你的密码——密码只有加密后的哈希。

**Q：链接打不开？**
A：站在微信里先试试「在浏览器打开」；仍然不行多半是网络问题，切成流量（移动数据）或换个网络再试。站点只有一个入口地址，不存在「换备用链接」这一说了。

**Q：网站会一直更新吗？**
A：会。内容随仓库实时更新，打开即是最新版；装到桌面后无需重新安装。

## 更新日志

> 完整历史可在后台「版本更新」面板查看，这里只列近几个大版本。

### v3.5.17（2026-10-18）—— 歌单投票选项带上完整信息

- 后台「从点歌平台挑歌」勾选后，选项文字改为 **`歌名 - 歌手 - 点歌人 - 点歌时间`**（缺项自动跳过，如匿名点歌显示「匿名」）。
- 列表里也把四段都露出来，方便确认是哪一版、谁点的、什么时候点的。
- 选项长度上限 40 → **80**（40 字会把时间截掉）；学生前台加选项的输入框同步放宽。

### v3.5.16（2026-10-18）—— 修复批量导入「同一列被赋值两次」

- **症状**：导入资料时 60 多行全部失败，报 `multiple assignments to same column "id_card"`。
- **根因**：`id_card` / `youth_league_no` 既在「固定列」逻辑里（`idCard`），又在「可编辑字段」清单里（`extra.id_card`），拼接 SQL 时同一列出现两次，PostgreSQL 直接拒绝整条语句。
- **修复**：服务端把固定列从自定义列里排除；UPDATE 的 SET 与 INSERT 的列名再做一次去重兜底；前端也不再重复采集这两列。
- 顺带说明：导入弹窗上的「取消」只是关闭弹窗，**不会撤销已入库的行**。

### v3.5.15（2026-10-18）—— 时间字段支持精确到月/年

- **日期校验分精度**：字段规则的「时间」类型新增「精确到」——**日 / 月 / 年**三档。
  - 精确到月：`2024-05`、`2024/5`、`2024年5月`、`2024.5` 都能导入；写 `2024-05-13` 也接受，入库统一存 `2024-05`。
  - 精确到年：`2024` 就够。
  - 精确到日：仍要求完整日期（`2024-05-13`），并挡掉 `2024-02-31` 这类假日期。
- **导入容错**：Excel 日期型单元格带出的 `2024-05-13 00:00:00` / ISO 串、以及 Excel 的日期序列号（如 45306）都能正确识别。
- **写库前规整**：按字段精度统一入库形态，单条保存与批量导入两条路径都走同一套规整。
- **规则编辑器**：「时间」规则多了「精确到」下拉，区间输入框跟着变成日期 / 年月 / 四位年份。

### v3.5.0（2026-10-17）—— 成员档案全量加密

站主要求「成员档案里的所有信息，姓名、学号、身份证、微信等等全部加密储存」，本轮落地。

**① 加密范围**

| 字段 | 是否加密 | 说明 |
|---|---|---|
| 姓名 / 学号 | ✅ | 另存盲索引供检索与去重 |

- 学号的 `unique` 约束**去掉**了（密文永不相等，留着反而会在更新时报冲突），唯一性由应用层查盲索引保证。

**③ 迁移与降级**

- 老库自动补列（`http.js` 自愈），不用手工执行 SQL；
- 存量明文**边用边转**：管理员下次保存那条资料时顺手加密，没动过的仍是明文，明文密文混存是正常状态；

- ⚠️ 密钥千万别删、别改：删掉之后已有密文再也解不开（后台会显示「已加密，但未配置 ADMIN_SECRETS_KEY，无法解密」）。

**① 字色判定函数本身不准（核心）**

v2.9.10 的 `clsLuma` 用的是线性 YIQ 加权亮度，不是 WCAG 相对亮度，中间色会误判：

### v2.9.10（2026-10-16）—— 全站字色自适应 + 成绩分析备注官方化

**① 全站字色共用一套逻辑：按背景实时取相反色**

站主原话：「全站字色共用一套逻辑……字体颜色需根据背景颜色实时改变，都用对应的相反色，

| | 改之前 | 改之后 |
|---|---|---|
| 渐变/彩色背景上的文字 | 各处写死白字或深字 | 一律过 `clsReadableOn(背景色)` 取相反色 |
| 白天/黑夜切换 | 只有 CSS 变量覆盖到的地方跟着变 | 主题切换即全局重算，JS 渲染的也扫 |
| 新增渲染点 | 自己掂量字色 | 加 `class="ink-auto"` 即可，动态背景用 `data-ink-bg` 声明 |

实现就四个函数（index.html 与 admin.html **逐行同构**，e2e 有断言盯同构）：
`clsParseColor`（#rgb/#rrggbb/rgb()/rgba()）→ `clsLuma`（YIQ 加权亮度）→
`clsReadableOn`（亮度 >0.6 用深字 `#241f1c`，否则白字）→ `clsAutoInk`（扫描 `.ink-auto` 重设字色）。
`clsAutoInk` 优先读 `data-ink-bg`，否则读 computed `backgroundColor`；
读不到有效色时从 `background-image` 渐变里抓第一个色当代表色 —— 渐变色取自 CSS 变量，
换主题会实时变，字色跟着变。另挂了一个 debounce 100ms 的 MutationObserver 兜底：
面板/表格动态渲染出来的 `.ink-auto` 也会被自动扫到，不必每个渲染函数后面手动跟一次。

### v2.9.9（2026-10-16）—— 一次性根治「首次登录改密卡死」

站主第四次报同一个问题：「用户登录还是卡在设置新密码，提示旧版加密格式超限，要管理员重置」。
前几轮都以为是 Worker 的 CPU 预算不够（免费版单请求 10ms 装不下两次密码加密运算），
加过护栏、降过迭代次数，都没根治 —— 因为**这个判断本身就是错的**。

**① 先拿线上数据，再动刀（临时诊断端点）**

上线了一个只读诊断接口（用完即删），一次问清三件事：

| 问题 | 线上实测 |
|---|---|
| 密码哈希格式分布 | 63 个账号：老格式 63、bcrypt 0、新格式 0 |
| 迭代次数分布 | 10000 次 2 个、**50000 次 61 个** |
| CPU 预算到底多少 | 单请求连跑 **60 次** PBKDF2(10000)（合计 60 万次迭代）稳定 200 |

第三条直接证伪了旧归因：CPU 预算从来不紧。当年改密 500 的真凶是
**建表脚本漏了 `failed_count` / `locked_until` 两列**（ensureSchema 已修，与改密无关的请求先暴露了它）。
而基于误判加的 `needsDowngrade` 护栏（50000 档位账号禁止自助改密、只能管理员重置），
防的是一个不存在的 500，却把**全班 61 个账号的首次登录改密全拦死了**。

**② 根治：把密码加密从服务器搬到浏览器**

| | 改之前 | 改之后 |
|---|---|---|
| PBKDF2 在哪跑 | Cloudflare Worker（有单请求 CPU 预算） | 用户手机/电脑浏览器（没有这个概念） |
| 改密时服务器运算 | 派生旧密码 + 派生新密码（2 次 50000 档） | **零次**，只比一次摘要 |
| 老手机跑 50000 次 | —— | 本地约 1–2 秒，页面转圈等待 |
| 库里存什么 | 可直接登录的密钥 | **不可反推的摘要**（拖库也拿不到登录密钥） |

协议三步：浏览器问服务器要「盐和迭代次数」（未知用户名返回诱饵参数，防枚举）→
本地 PBKDF2 派生 → 登录/改密只发派生结果。服务端 `verifyCredential` 零派生、常量时间比对。

**③ 兜底与兼容**

- 老浏览器没有本地加密能力（或盐接口临时 429/挂掉）→ **自动回退**旧明文路径，行为与以前一致
- 明文路径对所有账号照旧可用（e2e 有锁定用例），管理后台单次派生仍是 10000 档
- 顺手修了「改密前刷新页面被迫退出重登」：现在刷新后仍停留在设置页，补一个「当前密码」输入框即可

测试：**1651 → 1681 全绿**（新增 30 条：盐接口三态与限流、凭证登录/改密的成功与各类失败、
畸形哈希拒绝、刷新恢复标志的 me 两态、以及前端两个页面接线点的正则护栏）。

### v2.9.1 – v2.9.4（2026-10-14）—— 还原演练：连着揪出四个真 bug

> **做备份却从没验证过能不能恢复，等于没做。** 本轮就是真刀真枪演练一次，
> 结果连炸四个 —— 全都是「只看代码看不出来」的那种。

| # | 问题 | 后果 | 修法 |
|---|---|---|---|
| 1 | 还原逐条 insert | Workers 免费版**每请求最多 50 个子请求**，Neon 每次查询就是一次。121 条只插进 37 条就 500 | 改 `jsonb_to_recordset` 批量灌 |
| 2 | 快照里日期是 ISO 串 | `2026-07-02T00:00:00.000Z` 喂回去不认 | `isoDay()` 统一成 `YYYY-MM-DD` |
| 3 | 还原是「先 delete 再 insert」 | insert 失败 → **数据被清空且插不回去**，比不做还原还糟 | 整套动作放进 `sql.transaction`，只会全成功或全回滚 |
| 4 | `String(dateObj)` 不是 ISO 串 | 正则静默失配 → 快照里日期全变 null | `isoDay()` 单独处理 Date 实例 |

**顺带**：改分 `scores-save` 原先也是逐条写 —— 后台「块粘贴」几十行同样会 500，
一并改成批量 upsert；还原失败时现在会回传**真实原因**（原先只说「服务器内部错误」，没法排查）。

**演练最终结果：12/12 全绿** —— 还原后 121 条成绩一条不少、抽样总分一致、
分享记录恢复、还原后新建考试不撞主键、一次改 60 行不报错。

### v2.6.4（2026-10-13）—— 自动检查更新 + 一键强制刷新（修「iOS 刷不了」）

**问题**：站主在 iPhone 上发现线上已经 2.6.3，自己这边还停在 2.6.2，怎么刷都不动。

**根因不是代码没推上去**，而是 iOS 极少主动检查 Service Worker 更新 —— 尤其「添加到主屏幕」后，浏览器只在导航时、且最长 24 小时才查一次；而新版本装好后，已打开的页面也不会自己重新加载。

**改动**：
- 进站即检查更新；另外**回到前台**（切出去又切回来）与**每 5 分钟**各查一次
- 对比线上版本号（读 12KB 的 `sw.js`，不是 600KB 的首页），落后就在页脚显示醒目的「发现新版本 · 点击立即更新」

- 页面刚打开 15 秒内发现更新会**自动刷新**（用户无感）；用得久了则只提示，不打断正在用的人
- 设置面板「数据」页新增「版本与更新」：并列显示当前版本与线上版本

**顺带修掉两个隐患**：
- 版本探测用的 `?_=时间戳` 请求原先会被 SW 写进缓存 —— 每 5 分钟查一次，一天能堆几百份副本
- 强制刷新时 SW 还活着，会把刚删掉的缓存又写回来（改为先注销再清，并连清两轮）
- 版本探测原本要下载整个 600KB 的首页（弱网下 30 秒都下不完、还费流量），改读 12KB 的 `sw.js`

  |---|---|

  连上立刻显示「连接已恢复」再自动收起，60 秒走完还没成功就回到原提示、按钮还在可以再点。

### v2.5.2（2026-10-11）—— 修复「正常联网却提示连不到服务器」
- **修复（重要）**：站主反馈「手机明明连着网，页面却弹『连接不到服务端』」。
  排查发现**根因不在站主的网络，而在服务端太慢**：实测 TCP 握手只要 0.2 秒
  （网络完全正常），但带 token 的心跳请求首字节要 **1.4–10.1 秒** ——
  而前端的超时阈值只有 **12 秒**，最慢的一次只差 **1.9 秒**就误判离线。
  手机在移动数据 / 信号弱时延更大，必然突破 12 秒，于是弹出了那句误导人的提示
- **服务端提速**：心跳里原本有**两条串行的 UPDATE**（会话级 + 用户级 `last_seen_at`）。
  Neon 走 HTTP 传输，**每条 SQL 都是一次 HTTPS 往返**，串行就是两次。
  现在改为**并发发出**（`Promise.allSettled`），耗时从「两者之和」降到「较慢的那一条」
- **前端超时放宽**：心跳超时 `12 秒 → 30 秒`，离线宽限期 `25 秒 → 60 秒`。
  60 秒正好覆盖一整轮心跳周期，只有**真的连续两轮都收不到 pong**才提示
- **文案不再误导**（站主要求）：区分两种失败原因
  - **真连不上**（DNS / 断网 / CORS）→「连接不到服务端…请检查网络，或切换到流量」
  - **服务器响应慢**（超时 / 5xx）→「服务器响应较慢…正在自动重试」，
    **不再让用户去换流量**（换了也没用，只会白折腾）
  - 两者同时出现时以「真连不上」为准（更严重者优先展示）
- 新增 8 条回归护栏断言（含「**禁止**把超时改回 12 秒」）防止复发

  （前端发一次、服务端回一次 `pong`），按**会话粒度**记录 `sessions.last_seen_at` —— 不再是你登过一次
  就一直挂着「在线」。后台「用户管理」和「在线会话」都按这个口径显示
- **登录 / 注册加人机验证**：拖动滑块拼图，纯前端实现（不联网、不上传、不收集任何信息），
  用来挡掉脚本批量注册和撞库
- **游戏数据不再跨游戏合并**：以前后台会把一个人在所有游戏里的时长加成「总时长」并据此排序 ——
  但上午玩贪吃蛇、下午玩飞鸟是两码事，加在一起没有意义。现在**各游戏独立展示**（各自最高分 / 局数 / 时长），
  排序改成「最近玩过谁」，汇总口径改成「累计局数（局）」
- **全站图标统一为 SVG 图标库**：彻底移除运行时的 emoji → 图标替换引擎（它靠 `MutationObserver` 监听
  整页 DOM，和每秒刷新一次的倒计时打架，导致 emoji **每秒闪一下**）。现在全部改成静态 SVG 图标，
  **闪烁消失**。公告 / 作业正文里的手写 emoji 也在渲染时一次性转成图标
- **连不上服务端有明确提示**：网络中断或服务端不可达时，页面顶部会显示「连接不到服务端，当前显示本地缓存 ·
  请检查网络，或切换到流量（移动数据）再试」，恢复后自动消失
- **取消备用链接**：旧的 Gitee Pages 早已下线，WorkBuddy 托管那条微信内打不开、还容易误导同学，
  现在全站只有 GitHub Pages 一个入口；README 与站内文案同步精简
- 测试从 911 项扩到 **1006 项全绿**

### v2.4.1（2026-10-09）—— 后台权力最大 + 手机端排版修复
- **⚠️ 可见性语义调整（重要）**：取消 v2.4.0 的「三层取严」，改为**「你调过的字段你说了算，你没动过的尊重同学」**。
  起因是取严有个致命副作用 —— 你**永远无法放宽**（同学设了「仅自己可见」，你改成「公开」也白改）。
  现在：① 你在字段管理里改过某字段 → 以你为准，可放宽可收窄；② 你在某个同学的编辑弹窗里设过例外 → 以你为准，只对他一人生效；
  ③ 你没动过的字段 → 同学说不想公开就一定不公开
- **后台编辑弹窗会反向提醒你**：某同学自己设了私密时标「本人已设为私密」；被你覆盖时标「已被你覆盖」
- **前台同步告知同学**：个人中心写明「站主为核对资料在后台仍能看到；若站主调整过该字段的可见范围，则以站主设置为准」
- **修 🐞 后台「仅本人可见」勾选项排版重叠**：CSS 类名撞车 —— 全局 `.chk`（给表格里真复选框用的 `width:15px`）
  把表单里的 `<label class="chk">` 也压成了 15px 方块，文字逐字竖排并和上下的提示文字叠在一起
- **修 🐞 头衔任命只有一页、没有换页入口**：62 人时看不全。现在加了「首页 / 上一页 / 页码 / 下一页 / 末页」
  五个按钮 + 「共 N 人，当前显示第 X–Y 条」的说明，搜索和刷新会自动跳回第 1 页
- **修 🐞 窄屏表格被压扁、名字一列一列竖着排**：`table{width:100%}` 在 390px 手机上把 5 列各压到 ~70px，
  中文两字就溢出断行。现在窄屏下表格保持 640px 最小宽度、可左右滑动，单元格内文字不再逐字换行
- **修 🐞 单人例外对微信/QQ/手机号静默失效**：`buildFieldVis` 的白名单原本错用了「可自定义字段」名单，
  而这三个字段恰不在其中 → 你在编辑弹窗里给某人设的例外被**静默丢弃**、点了保存也不生效（v2.4.0 起就存在）
- **修 🐞 新增资料时「仅自己可见」意愿被丢掉**：保存接口的 INSERT 分支漏写了 `visibility_pref` 列，
  于是给同学设了私密后再**新建**资料，这份意愿永远存不进去（只有走「编辑」才生效）——线上验收才抓到
- 测试从 868 项扩到 **911 项全绿**

## 技术说明

- 前端：纯静态 PWA —— 单文件 `index.html` + `games/` 小游戏 + Service Worker 离线缓存
- 图标：站内不用 emoji 渲染，统一走内置的 **Lucide SVG 图标库**（避免 emoji 在刷新时闪烁、各系统外观不一）
- 后端：Serverless 云函数（当前部署在 Cloudflare Workers）+ 云数据库，支撑账号登录、个人数据云同步、云端内容（公告 / 作业 / 重要日期 / 每日一言）与管理员后台；后端说明见 [`api/README.md`](api/README.md)
- **不登录也完全可用**：不注册时个人数据只保存在你自己的设备（localStorage）里，不上传服务器
- 仓库开源：GitHub `yuzikaaang/class-site`（主仓库，GitHub Pages 直接发布）；Gitee `zikang0529/class-site` 为镜像
- 站内「导出备份」可下载完整站点备份包（需备份密码）
